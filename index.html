Tentang FitsMatch AI

Platform fashion AI yang memadukan teknologi terkini untuk membantu kamu tampil percaya diri setiap hari.

🤖

Google Gemini AI

Ditenagai Gemini 1.5 Flash dari Google untuk menghasilkan rekomendasi outfit dan percakapan fashion yang natural dan kontekstual.

📷

Teachable Machine

Model klasifikasi pakaian dilatih dengan Google Teachable Machine dan berjalan langsung di browser menggunakan TensorFlow.js.

⚡

TensorFlow.js

Inferensi model machine learning berjalan di sisi klien (browser) sehingga privasi terjaga dan tidak memerlukan server.

🔗

Integrasi Antar Fitur

Ketiga fitur saling terhubung. Hasil scan otomatis menjadi konteks chatbot sehingga AI memahami situasi pengguna tanpa input ulang.

🔒

Privasi Terjaga

Data tersimpan di localStorage browser. Semua fitur memiliki fallback offline sehingga tetap berfungsi tanpa API key Gemini.

📱

Fully Responsive

Dibangun dengan Tailwind CSS dan desain mobile-first. Berfungsi optimal di desktop, tablet, maupun smartphone.

🔑 Cara Menggunakan Gemini AI (Gratis)

  1. 1.Kunjungi aistudio.google.com/app/apikey untuk API Key gratis.
  2. 2.Klik tombol "Demo Mode" di pojok kanan atas navbar.
  3. 3.Masukkan API Key (format: AIzaSy...) lalu klik Simpan.
  4. 4.Semua fitur kini menggunakan AI Gemini secara real-time!
