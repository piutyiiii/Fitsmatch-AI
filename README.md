# 🤖 FitsMatch AI
An AI-assisted fashion recommendation web application that helps users discover outfit recommendations based on their preferences, weather, occasions, and clothing items.

## 🎯 Project Overview
FitsMatch AI is a fashion assistant web application designed to help users find suitable outfit recommendations.
The application provides several features including outfit recommendations, outfit scanning, and an AI fashion chat assistant.

## ✨ Features
- 🎯 Outfit Recommendations
- 📷 Scan Outfit
- 💬 AI Fashion Chat
- 🌤️ Weather-based outfit recommendations
- 👗 Occasion-based outfit recommendations
- 🎨 Style and color preferences
- 🌙 Dark & Light Mode
- 📱 Responsive Web Design

## 🛠️ Technologies
- HTML
- CSS
- JavaScript
- Tailwind CSS
- TensorFlow.js
- Teachable Machine
